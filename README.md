## 工作约定
源码、素材、设计稿、原型及文档统一放在本目录。设计 idea 和改动通过可预览的 HTML 或其他可视化成果展示，详细规则见 AGENTS.md。

## 入口页初稿（2026-10-07）
当前实现为无需依赖的 HTML/CSS/Canvas 交互原型，源码在 `dist/`。

运行：`node preview.mjs`，打开 http://127.0.0.1:4173 。

包含白底 Franco 字样、黑漆滴落、鼠标荧光绿显露、入口转场、移动端布局与减少动态偏好支持。右下角为角色接入位置；当前按钮演示转场，没有实现 3D 人物或人物推门动作。About 页面仅用于转场预览，没有个人介绍正文。

GitHub 同步不等于网站部署。弹幕、地图与经历尚未实现。
